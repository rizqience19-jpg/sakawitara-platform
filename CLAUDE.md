# sakawitara-platform

- Next.js 15 + Supabase: platform undangan pernikahan digital bertema Jawa (`app/`, `lib/`, `supabase/schema.sql`).
- `animasi/`: video cerita kartun desa (canvas 2D → MP4). **Sebelum membuat cerita/animasi baru, baca `animasi/PANDUAN-GAYA.md`** — berisi gaya visual, gaya voice over ElevenLabs (suara, model, tag), dan alur kerjanya.
- `animasi/hantu/`: kanal **Mesin Pengumuman** (maskot speaker kuning bermuka datar, tombol merah di kepala, ekor kabel), episode "Hantu Kena Sensor". Build: `python3 animasi/hantu/sfx.py && node animasi/hantu/build.js`. Suara dialog ElevenLabs disimpan di `animasi/hantu/suara/`.
- `animasi/lampu-merah/`: "Konser di Lampu Merah" (gaya Mbah Darmi, ±2 menit). Build: `python3 animasi/lampu-merah/sfx.py && node animasi/lampu-merah/build.js`. Waktu kata diambil dari transkripsi ElevenLabs (`suara/narasi-words.json`); narasi dipotong per baris lalu ditata ulang dengan jeda komedi (kolom ke-7 di `SCRIPT`).
- `animasi/hajatan/`: "Nasinya Masih Muter" (gaya Mbah Darmi, ±2 menit; latar & tokoh desa dari mesin Mbah Darmi). Build: `python3 animasi/hajatan/sfx.py && node animasi/hajatan/build.js`. Sama seperti lampu-merah (transkripsi per kata + jeda komedi), ditambah `TEMPO` untuk mempercepat narasi tanpa mengubah nada.
- `animasi/nastar/`: "Nastar Masih Disegel". `nastar-masih-disegel.html` = versi interaktif (speechSynthesis/rekaman, subtitle kalimat, tombol). `nastar-masih-disegel-video.html` = versi video gaya Mbah Darmi (narator Gunawan, caption satu kata, TEMPO 1,12) yang memakai gambar yang sama. Build video: `python3 animasi/nastar/sfx.py && node animasi/nastar/build.js`.
- `animasi/sapto/`: "Sapto Belum Nikah-Nikah" — **contoh acuan alur kerja terbaru** (narasi utuh 1 versi, waktu adegan & caption dari transkripsi per kata, efek suara pendek pelan, tanpa musik). Build: `python3 animasi/sapto/sfx.py && node animasi/sapto/build.js`. Kalimat yang perlu nada lain (gosip berbisik) dibuat ulang terpisah lalu disambung di jeda alami (`suara/narasi.mp3`).
- `animasi/rumah-kosong/`: "Rumah Kosong Keluarga Hardjo" (horor + celetukan, alur kerja Sapto: narasi utuh 1 versi, waktu dari transkripsi per kata, efek suara pendek pelan, tanpa musik). Build: `python3 animasi/rumah-kosong/sfx.py && node animasi/rumah-kosong/build.js`.
- `animasi/kuburan/`: "Kuburan Jalan Pintas" — episode ke-2 serial Bagas, Rehan, Tika (tokoh sama dengan rumah-kosong; kopdes 24 jam di tengah kuburan, pocong, kasir berambut panjang). ± 95 detik. Build: `python3 animasi/kuburan/sfx.py && node animasi/kuburan/build.js`.

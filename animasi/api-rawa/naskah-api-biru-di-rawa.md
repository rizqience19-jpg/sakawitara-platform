# Naskah: "Api Biru di Rawa" (Kisah Nyempil — serial Bagas, Rehan, Tika)

Pola Mbah Darmi (misteri desa → gosip warga → trio menyelidiki malam hari → "Ternyata…" → penjelasan ilmiah dengan zoom ke dalam lumpur → warga ikut mencontoh → kalimat penutup), dibawakan trio dengan celetukan. Satu narator (Gunawan, eleven_v4, 1 versi), narasi utuh, caption satu kata, efek suara pendek & pelan, tanpa musik. ± 2 menit, 36 baris.

Tokoh baru: **Pak Ranto** (peternak sapi, pernah dikejar "banaspati"), **Bu Wening** (guru IPA), ibu-ibu warung. Latar: rawa di pinggir Desa Kalibening (malam), warung, sekolah, kandang sapi.

Edukasi: api rawa (*will-o'-the-wisp*) — pembusukan tanpa oksigen menghasilkan metana; para ilmuwan menduga sedikit fosfin/difosfin yang menyala sendiri di udara menyulut metana; nyala ikut tertiup angin. Metana yang sama dimanfaatkan sebagai biogas dari kotoran sapi.

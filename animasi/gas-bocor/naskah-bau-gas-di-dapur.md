# Naskah: "Bau Gas di Dapur" (Kisah Nyempil — edukasi keselamatan)

Tokoh & tempat fiksi. Nada serius-hangat, tanpa lelucon. Narator Gunawan (eleven_v4, 1 versi), narasi utuh, caption satu kata, efek suara pendek pelan (desis gas, klik saklar), tanpa musik, -14 LUFS. ± 2 menit, 28 baris. Pola: kejadian → "kamu akan apa?" → 1. KALAU KAMU MENCIUM BAU GAS / 2. KALAU API SUDAH MENYALA / 3. MENCEGAH → akhir.

Tokoh: **Bu Ratmi** (ibu rumah tangga, daster ungu, kerudung), **Fajar** (anaknya, SMP), **Pak Joko** (tetangga). Latar: dapur rumah desa Kalibening (rak piring, kompor dua tungku, tabung 3 kg, jendela kecil, kalender).

Hook & thumbnail: "DIA CUMA MENYALAKAN LAMPU…" (kata-sorot: MENYALAKAN LAMPU).

Rujukan: Pertamina via Viva/Kontan/JPNN (cabut regulator, tutup valve dengan kain basah, bawa tabung ke tempat terbuka, matikan sumber api & listrik, call center 135); RRI 2026 (buka pintu & jendela); Damkar 113.
